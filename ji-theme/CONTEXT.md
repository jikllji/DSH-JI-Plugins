# ji-theme

DSH（DeepSeek Harness）Web UI 主题插件：为网页界面提供可切换的皮肤、可自定义的主题（颜色 + 背景图），并把壁纸作为真实文件持久化。宿主半提供壁纸文件存储与 HTTP 服务，浏览器半负责编辑、应用与展示。

## Language

**主题（theme）**:
一个完整的界面外观配置：配色（会话背景、表面、主/次文字、强调色等）+ 可选的背景图。用户可新建、编辑、导入。
_Avoid_: 皮肤（当指自定义配置时）

**皮肤（skin）**:
可被选中的主题选择项，包括系统跟随、浅色、深色与各主题；主题被选中时即为当前皮肤。
_Avoid_: 主题（当指「选择哪个外观」这一动作时）

**壁纸（wallpaper）**:
绑定到主题的背景图片。以真实文件存储在插件目录下，主题只保存其 URL 引用；浏览器通过 HTTP 加载。
_Avoid_: 背景图（指界面里的视觉图层时）、base64 内联图

**壁纸契约（wallpaper contract）**:
宿主侧唯一拥有壁纸上传约束（允许的媒体类型、体积上限、命名规则、URL 前缀、错误码）的模块；它通过契约端点把约束发布给浏览器半。浏览器半不复制任何约束，运行时获取。
_Avoid_: 上传规则、壁纸 API、存储配置

**错误码（error code）**:
宿主跨 seam 返回的稳定错误标识（如 `TOO_LARGE`、`BAD_PAYLOAD`），附带宿主兜底文案；浏览器半用 locale 字典把已知错误码映射为本地文案，未知错误码降级显示兜底文案。
_Avoid_: 错误字符串、错误消息（当指机器可读的标识时）

**壁纸存储（wallpaper storage）**:
壁纸文件在磁盘上的存放位置（插件目录下的 wallpapers 子目录），由宿主半管理；浏览器半通过存储路径展示（仅展示，不直接访问）。
_Avoid_: 上传目录、媒体目录
