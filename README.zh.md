# DSH-JI-Plugins

中文 | [English](README.md)

DeepSeek Harness (dsh) Web UI 的个人插件合集。

## 插件列表

| 插件 | 说明 |
| --- | --- |
| [ji-theme](ji-theme/README.md) | dsh Web UI 皮肤、自定义主题编辑器、DreamSkin `.zip` 导入 |

## 安装

每个插件都是一个 dsh bundle,完整步骤见各插件自己的 README;简要如下:

```bash
dsh plugin --profile web add <插件目录>
# 重启 dsh web 生效
```
